# 变更日志

## 发布：v0.98.1

## 功能

- **标签栏改回一行排到底：标签再多也不会把对话往下挤，放不下的收进「更多」；新打开的标签自动排到最前。**
- 标签栏高度固定，永远只占一行；每个标签按可用宽度自己缩，缩到底仍放不下就收进后面的「更多」菜单，悬停就能展开。
- 每打开一个会话，它就排到最前面，之前打开的那些顺次往后挪；「更多」菜单里也能看到哪个标签正在忙。

## 修复

- 深色主题下消息头那个状态小胶囊是蓝色的，改回和浅色一致的中性灰。
- 一轮回答结束后，思考与工具的时间线里还留着一段与气泡正文重复的内容，现在只显示一次。
- 浅色主题下工具的参数和结果都是灰的，分不清哪半是输入、哪半是输出；现在参数绿、结果青，与深色主题同一套语义。
- 「消息外观」里的字号以前只改聊天文字，跟设置页的字体大小是两套，两边还互不同步；现在两处是同一个设置，改一处另一处跟着变，这一项也统一叫「字体大小」。
- 加载时那个四片叶子依次亮起的小转圈一直是倒着转的，改成顺时针。
- 工具参数区、配置页这些地方的等宽文字用的不是应用自带的字体，Windows 上落到了系统里另一款等宽；思维链和时间轴预览里的小段代码也一样。现在全部统一到应用自带的那款。
