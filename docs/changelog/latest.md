# 变更日志

## 发布：v0.98.2

## 功能

- **回答正文、思考过程和工具卡片的高度改为平滑展开，收起与展开不再一格一格往上蹦。**
- 助理派子任务时改按类型委派，任务说明随委托完整交给执行方，不再中途丢内容。

## 修复

- 图片预览右上角的百分比按钮一直写着 100%，看不出当前放大了多少；现在显示真实缩放比例，回到 100% 时按钮置灰。
- 文件阅读器打开软换行后，滚动条长度和实际内容对不上，滚到底要来回好几次，按行号跳转也落不准；现在换行时按真实高度计算。
- 聊天记录滚动定位会因内容区上方的留白产生偏移，跳转落点不再偏上。
- 消息头部的状态小胶囊文字太长时会把布局挤乱，现在固定一行，放不下的交给外层截断。
