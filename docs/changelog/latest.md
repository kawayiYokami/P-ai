# 变更日志

## 发布：v0.98.4

## 功能

- QQ 官方渠道详情页多了「扫码绑定」：点一下出二维码，手机 QQ 扫完确认，AppID 和 AppSecret 自动填进表单，不用再手动复制。
- 预设主题里万圣节换成了绯红。
- 本地 HTML 卡片多了「在右栏打开」，不用再挤在气泡里看。

## 修复

- 启用 QQ 官方渠道时应用直接崩溃，现在不会了，扫码建连正常走通。
- 小代码块和小表格不再被折叠，保留原文直接看。
- 流式输出时思考过程和工具调用的「收起」按钮不再随滚动跳动。
- 提问面板选完选项后消息立刻出现，不再「刷」一下顶上去，也不再把输入框里的 @提及带进去。
- 发送覆盖不再清空输入框。
- 自定义答案输入框限制为 1000 字，超长不再截断失败。
- 新加的远程联系人不再默认用第一个供应商的第一个模型，会用你最后选过的模型。
- 长会话触发整理的时机统一，保留对话时超长单条消息会自动压缩，不再占满上下文。
