# 变更日志

## 发布：v0.97.9

## 功能

- **会话索引库损坏时，聊天报错卡片上会多出「自修复」按钮：点一下即整库重建并按块文件恢复当前会话，修完自动重读，不必再放弃这个会话。**
- **截图新增网格参考线：模型可自行决定在截图上加等分参考线，用来更准地描述位置；份数给得不合规会直接报错，而不是悄悄出一张干净图。**
- **图片发送前的尺寸预算放宽：手机截图、长图不再被压到小字糊成一片；图片确实被缩小时，会把原尺寸和实际尺寸一并告诉模型，避免它按原图精度误判细节。**

## 修复

- 其他会话在后台整理上下文时，本会话的撤回不再被误报成「当前会话正在运行」而拦下。
- 消息发出后立刻停止，界面不再卡在运行中，停止按钮和忙碌文案会正常消失。
- 供应商删掉最后一个模型后，刷新模型不再没有反应，点「放弃修改」也不再让详情页变成空白。
- 代码审查对话卡片的模型默认取当前会话模型，不再显示哨兵串或报「指定模型不可用」而发起不了审查。
- 挂载第三方 MCP 工具后整轮请求被上游拒绝的问题修复，这类工具现在能正常调用。
- 经中转或自建网关使用部分供应商时不再回「缺少会话标识」，会话标识会按协议正确带上。
- 回复流意外中断时不再当作正常结束，会直接报错，而不是把半截回复当完整结果。
- 文件阅读器里切换文件后目录树会跟着定位，从外部入口打开文件也不再漏掉定位。
- 用量足迹墙的格子恢复方砖观感，色阶改按当年实际用量分布，日常用量也能看出高低。
- 桌面操作遇到目标窗口卡死时不再长时间无响应，失败时会给出可读原因。
