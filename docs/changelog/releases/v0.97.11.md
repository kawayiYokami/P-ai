# v0.97.11

## 功能

- **助理用到的 MCP 工具不再每轮全部塞进上下文，改成需要时按名字拿取，拿过之后下一轮才带上参数；名字写错会给几个相近的候选。**
- **工具调用一开始执行就出现在消息里，不用等结果回来才显示；中途打断只停住还没返回的调用，已经跑完的结果照常保留。**
- **右栏的追问与队员磁贴显示人格头像，调度中转圈、有未读显示绿色角标、上轮失败显示红色角标，三个状态占同一个位置，一次只出现一个。**

## 修复

- 排队的消息在本会话发出后再切回来，输入框上方不会仍挂着已经发出的那条。
- 手机端回车或点发送后软键盘收起；点底栏按钮也不再先收键盘才执行。
- 撤回排队消息、或把排队消息转成引导后，光标直接回到输入框，可以接着改。
- 发送新消息时历史不再被顶得上下跳，等内容量完做一次平滑上推；引导消息落库时同样平滑滚到底。
- 同一条消息里思考与工具同时只展开一个，跨消息也只保留一个展开位，不再因为同时铺开多块大正文而卡住。
- 思维链贴顶时不再持续往控制台刷警告，页面不会因此发卡。
- 打开追问会话直接落到最新消息，不再停在列表顶部。
- 追问窗口不再冒出主会话的轮次错误；追问压缩时会显示整理中提示并锁住输入。
- 修改文件时若漏了要替换的原文，现在直接报错，不再把整份文件静默清空。
- Web 端与 VS Code 侧边栏点会话索引库的修复不再没反应。

## 性能

- 助理状态显示更准：区分「正在生成工具调用」与「正在执行工具」，准备上下文、等待回应、开始输出各自独立显示。
