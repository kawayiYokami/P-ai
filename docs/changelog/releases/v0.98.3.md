# v0.98.3

## 修复

- **长会话触发上下文整理后，停止按钮点下去没反应、回答停不下来；现在整理完成后依然能随时中断。**
- 提问面板选完选项要等一会儿消息才出现，出现时又「刷」一下顶上去；现在点完立刻显示，并平滑上推。
- 折叠过程消息时会把长篇分析一起收进「上 N 条消息」里，读不到内容；现在只看长度，两百字以上的长段与最后一段始终展开，折叠条也改称「N 条消息」。

## 功能

- Git 面板的提交行在鼠标悬停时会收起 main、origin/main 这类分支标签，正文可以占满整行读完提交信息。
- 危险命令被本地规则拦下时，回执直接给出要回填的那句话，不再含糊其辞地来回试错。
