# v0.98.7

## 功能

- 停止回复时，已经生成的内容会当场保存下来，被打断的这一轮不会再冒出来继续往下跑
- 输入面板底部改为「加号、模式、模型、发送」；点加号可以添加图片、添加文件、添加议题，添加图片时只列出图片格式
- 上下文占用从标题栏移入输入面板，点开是一张上拉卡片，列出系统提示词、工具 schema、正文、保留区与剩余可用的占比；「整理」点下即压缩
- 计划、护航、目标三种模式改为互斥，开一个另外两个自动关闭；名称统一为「计划模式 / 护航模式 / 目标模式」，操作统一叫「退出」，悬停能看到一句话说明
- 下拉菜单统一为毛玻璃外观，切换主题后立刻跟着变色

## 修复

- 启动目标会闪退
- 创建目标后不再自动替你开始一轮对话，目标只在你说下一句时作为上下文生效
