# v0.90.0

## 功能

- **能力商店**：配置页新增能力商店，可跨魔搭、Smithery、官方 MCP Registry 检索 MCP 与技能并一键安装，装进来的默认是关闭状态；需要密钥的 MCP 会在安装前要求填写。
- **技能管理**：技能此前只能查看和编辑，现在可以整体启用或关闭；列表区分为自定义技能与系统内置技能，自定义技能能改名称、描述和正文，也能删除，内置技能只读；技能附带的其他文件可以直接查看。
- **配置页改版**：技能、供应商、部门、人格、连接器、渠道六个模块，由下拉单选加长表单改为卡片概览，点进卡片看详情；部门与人格增加「自定义 / 系统预设」分类，各模块都支持搜索。
- 人格设定词和技能正文支持 Markdown 预览与编辑切换。

## 修复

- 在输入框用 Tab 打开快捷指令、或用 @ 打开提及面板时，弹层被会话工具条压住、选项看不全，现在正常盖在工具条之上（引入于 v0.89.0）。
- Codex 供应商的模型下拉里缺少 gpt-6-astra，现在会随后端清单自动出现（引入于 v0.84.0）。
- macOS 26 上让 AI 模拟组合键会让应用直接崩溃，现已不再触发（引入于 v0.9.9）。
