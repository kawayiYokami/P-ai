# v0.97.4

## 功能

- **护航建议按对话状态分三种情况给出**：对话顺畅时，护航会给出 2~4 个你接下来可以直接发送的短语；你被误解、卡住或情绪上来时，护航提示你换个问法或先接住你的情绪；助理答非所问、术语堆砌、反复确认、停在汇报上时，护航把修正方向直接给助理下一轮。
- **护航建议不再是一段分析**：建议压缩成一句可直接用的话，不再解释推理过程，也不再复述你们刚刚说过什么；给出的快捷短语就是你自己的口吻，点了就能直接发送。

## 修复

- **修复助理陷入死循环时护航反复叫醒它**：护航原来每次都会把修正意见发给助理，而每次发送都会强制唤醒助理再跑一轮，助理没改好就会一直循环下去；现在护航先提醒助理一次，如果它还在重复，就停止给助理发消息，改为把情况告诉你，并给你一句能直接说出口的打断话。
