# v0.89.0

## 功能

- **PAI CLI（Beta）**：在终端里也能用 PAI。不开窗口、不弹界面，给一句任务跑完一整轮（含多轮工具调用），最终回答直接打在终端上；桌面端配好的 skill 与 MCP 在 CLI 里同样可用。用法 `p-ai run "<任务>" --model <配置>`。
- **流式预览**：聊天窗输入框上方新增预览条。生成中，上面四行思维链按阅读节奏逐行推进，下面一行展示最新一段正文；不生成时显示最新一条回复的正文。它同时接过「回到最新」的入口——聊天窗右下角那个圆形「回到底部」按钮已移除。
- **操作区重做**：时间线按钮、预览条、工作区栏这三处原来各自漂浮的元素，收进输入框上方同一个操作区，分上下两排。贴底时显示下排工作区栏，往上翻时显示上排预览条与时间线按钮。
- 操作区下排的元素改为彼此独立：工作区、运行监控、自动推送各自按条件出现，放不下自动换行，点一次直接执行（原来是一条会伸缩的胶囊，点一次只是展开）。工具栏上的 @ 提及入口去掉，输入框自带的面板已经覆盖。
- 生成过程中向上翻看历史，视口不再被强行拽回底部；回到最下方或点预览条才恢复跟随。
- 发送消息后，你的消息停在视口顶部，回复从下方接上。
- 运行监控胶囊按运行类型分流：只跑委托或任务时打开对应页，只跑后台进程、或多种混合时打开主页卡片墙。
- 主页面板新增「Git 提交」卡，能直接看到最近的提交。
- 设置菜单左侧加上分组标题，部分分组可折叠；折叠时组里有更新提示会在标题上显示红点。

## 修复

- 展开「思考与工具」时思维链先撑开再收起，现在直接以折叠态出现。
- 切换会话后，Git 更改区可能显示成别的会话仓库。
- 切换会话后，正在输出的助理气泡会丢掉流式样式。
- 打开会话先闪出第一条消息、不落在最新一条。
- 左右分栏打开时，时间线浮层会飘出聊天列。
- 自主权限档位在界面上与「全权」混同、权限范围被说小，现在单独显示为「无限制」。
