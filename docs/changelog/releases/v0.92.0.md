# v0.92.0

## 功能

- **会话时间线新增入口**：对话窗口底部的操作条右侧新增时间线按钮，点一下直接打开会话时间线，不必再先把鼠标移到悬浮按钮上等它展开。它与原本那个悬停入口位置重合，贴底与离底切换时按钮不再左右跳动。
- **Windows 上对话窗口卡住后能自行恢复**：内容渲染进程无响应或崩溃时，应用会自己重载或重建该窗口，用户不必重启应用；同时把失败原因与 WebView2 运行时版本写进运行日志，下次报障能查到依据。
- **改完技能、连接器和人格文件后可以立即生效**：让 AI 通过配置工具改这些文件后直接让运行中的应用重新加载，不用重启。

## 优化

- 时间线面板点空白处即可关闭；遮罩改为压暗加模糊，面板底色改为不透明样式。
- 时间线里的头像不再半透明，发言人名字去掉粗体、颜色变浅。
- 配置页页签去掉图标。

## 修复

- 生图供应商页面点任意卡片都会进入第一个供应商，现在会进入点中的那一个。
- 对话窗口里选中文字后点击按钮，可能造成窗口失去响应，现在已恢复对应处理。
