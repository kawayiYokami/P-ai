# v0.97.0

## 功能

- **新增「护航」模式**：开启后，每轮回答结束会再给一条沟通建议，可以是给你的点评，也可以是一组可直接点选的下一步；工具栏会出现「护航」标记，和计划模式同一个菜单里开关，开启前会提示这会明显增加 token 消耗。建议只有在你点了某个选项、或自己直接发言之后才消失，切会话、刷新界面都还在。
- **联系人新增 QQ 官方机器人渠道**：填 AppID 与 AppSecret 就能接入 QQ 单聊和群聊，支持收发文本、图片与文件，断线会自动重连；机器人还没过审核时勾上「使用沙箱环境」即可。
- **新建工作树可以直接检出已有分支**：新建工作树时可在「基分支 / 目标分支」间切换。选「基分支」还是从该分支派生新分支；选「目标分支」就是直接检出某个已有分支，工作树名称只作目录名。已被其他工作树检出的分支会标出来并禁止选择。
- **新增开机自启**：设置「常用」页新增「启动」分组，打开开关后登录系统就自动启动 PAI，并且静默待在托盘里、不弹窗口。
- **模型请求失败重试覆盖更多情况**：除了限流和模型空回，服务端错误、连接中断、超时也会重试；重试间隔改为逐步拉长，界面会显示「正在重试」。重试次数由供应商设置里的「失败重试次数」决定，默认 5 次。
- **联系人分组重命名改为就地编辑**：右键分组选重命名后，名字直接变成输入框，回车提交、Esc 取消，错误提示显示在该分组下方。

## 性能

- **长会话里打开撤回预览不再卡顿**：预览只读取要被撤回的那一段，耗时不随会话长度增长。

## 修复

- **修复桌面脚本在目标程序无响应时会卡死、停止按钮失效的问题**：目标窗口不响应时（例如被调试器断点挂住），点击、查元素、截图等操作会一直不返回；现在会限时返回，停止也能真正中断。
- **修复供应商没填并发上限时被当成串行、多会话互相挡住的问题**：以前不填上限等于一次只能跑一个请求；现在不填就是不限制，只有明确设成 1 才串行。
