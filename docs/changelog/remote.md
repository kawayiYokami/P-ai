# 变更日志

## 发布：v0.94.6

## 修复

- **修复新建会话失败、整个新建入口被锁死的问题**：曾经创建并删除过人格后，残留的人格记录会让新建会话一直报「会话草稿缺少可用的助理人格」而无法创建。现在助理人格固定为内置的默认人格，不再受残留记录影响，新建会话恢复正常。
- **修复「系统准则」开关切了也不生效的问题**：人格编辑页里的「系统准则」开关切换后，保存按钮一直不亮，开关的值发不出去，表现为开关完全没有反应。现在开关变化会被正确识别，保存后立即生效。
- **新建草稿继承当前会话的人格，人格缺失时不再阻断新建**：在某个会话里点新建，草稿直接沿用当前会话使用的人格，不再一律回到默认人格；系统通知会话、远程联系人会话不继承，人格已被删除时自动退回默认人格，不会因为一个失效人格就卡住新建。

## 发布：v0.94.3

## 修复

- **工作树模式下终端命令不再被误判越界**：会话绑定工作树后，命令的默认目录直接落在工作树里，执行命令不会再被「不在允许目录」挡下。
- **工作树模式下写文件与打补丁不再被误判越界**：在工作树里改文件、应用补丁能正常通过权限校验，不再提示目标不在允许范围。
- **进行中任务在磁贴与会话工具栏同步显示**：AI 创建或完成任务、调度器触发任务时，磁贴卡片与工具栏胶囊会即时刷新状态，不再需要切换会话才更新。

## 发布：v0.94.2

## 修复

- **MCP 服务可以完成 OAuth 授权登录**：连接需要授权的 streamable_http 服务时，配置页会出现登录入口，通过本地回调完成授权并把凭据保存下来；授权被拒绝时直接结束流程，不再一直等到超时。
- **网页搜索换用新的首选来源，并修正必应兜底**：降级链调整为 AnySearch → Exa → Bing，AnySearch 匿名可用、无需 API key；必应兜底不再返回品牌缓存导航页，改走 www.bing.com 取真实结果。
- **发送消息不再自动创建工作树**：会话工作树改为完全由工作区配置显式选择，未选择时按主工作区放行写入，不再默认在会话目录下建树。
- **主会话模型与会话首选对齐**：发送链路不再被人格主模型影响，未设置会话模型时明确报错；人格编辑里委托模型的改动（如「跟随会话」）现在能正常保存。
- **魔搭 MCP 条目不再把 JSON Schema 字段误当环境变量**：无变量的条目不再被误标「需密钥」，也不再弹出 properties / required / type 三个伪变量表单，旧缓存自动失效重拉。
- **调试日志恢复可用工具与请求头**：调度事件不再显示「无可用工具」，请求头不再缺失。

## 发布：v0.94.1

## 修复

- 图像生成供应商的编辑不再静默丢失：切列表页/详情页时若未保存，会先弹「保存并离开 / 放弃修改」；空列表下新增供应商不再失败。
- 首页工作区卡片在工作树与工作目录之间可切换：工作树态显示分支名并点击展开工作树目录，工作目录态显示主目录名并打开主目录；普通目录保持原样。
- 新建工作树的基分支改用分支树选择：本地/远程分组、按斜杠折叠，处于工作树时也能拿到完整分支列表。
- 文件阅读器提交行的 ref 徽章合并同类并折叠超量：同一提交上的本地与远程跟踪分支合并为一个徽章，单行超过 3 个折叠为 +N，悬停展开完整来源。

## 发布：v0.94.0

## 功能

- **工作区选择器改成「目录 → 工作树 → 分支」三级联动**：先选目录，再从该目录下的工作树里选，最后选这条工作树真实检出的分支；被别的工作树占用的分支直接禁用，不再出现「选 main 又勾工作树」这类矛盾组合。新建工作树就地填基分支与名称，确认即建好并选中，不再等到发第一条消息才建。
- **工具结果改成按需加载**：历史里不再把工具执行的完整结果塞进页面，只显示「结果已省略」占位；点开工具详情、再点「查看结果」才按需拉取，和模型看到的一致。
- **思维链和正文支持 Markdown 渲染**：思维链按行内渲染，正文按完整 Markdown 渲染（段落、标题、列表、表格、代码块、引用），工具详情仍保持纯文本，不会被解析破坏。
- **工作目录卡可以直接打开终端和常用应用**：Git Bash、PowerShell 7、Windows PowerShell、WSL、VS Code、资源管理器随选随开，文件阅读器共用同一入口；手机上自动隐藏。
- **read_media 拿到的图片一律原样返回给能看图的模型**：不再绕一道图片转文字；音频、视频仍返回文字描述，未配置对应模型时给出的是可照做的配置指引，而不是一句报错。
- **配置向导重做、完整设置成为主流入口**：标题栏不再挂「简单/高级」切换，首次配置走全屏向导直通聊天；未配置时欢迎页给出「配置模型供应商」主推荐和「快速配置向导」两条路。
- **设置页有草稿守卫**：改到一半切分类或关页会先弹确认，可选保存并离开、放弃修改或继续编辑；供应商不再强制要求填模型名，模型卡可以删到 0 张。
- **远程联系人模型三层分离**：联系人的模型统一挂在会话上，同一份配置只有一处来源，私聊直答与群聊应答都按它走；委托新增「跟随会话/专家/快速/自定义」四选一。会话被删或归档后只禁用模型选择，不重建、不猜数据。
- **远程应答委托标题改成触发消息摘要**：列表里直接看到这次应答针对哪句话，不再是一串联系人 ID。

## 修复

- 工具参数被模型生成为截断或非法 JSON 时，不再原样回放给供应商导致会话中断：这类调用拒绝执行、按文本回放，会话能继续。
- read 工具读 PDF 图片模式不再被文本预算截断，页图走图片通道，模型能拿到完整页面。
- 工具详情区现在会显示执行返回的结果，「工具结果没上报」的假象消失。
- 工具标题里的超长命令改为单行截断、折叠成第一行加行数提示，不再把多行脚本撑满一屏。
- 相邻的加粗文本（如 Step1、Step2、Step3 连写）自动分行，思维链流式输出不再糊成一块。
- Git 面板的「修正」按钮支持空提交信息，走合并暂存改动到上一个提交的语义，保留原提交信息即可。
- 草稿态切换工作区时，Git 面板会跟着刷新到新仓库。
- 工作树模式下 Git 面板的「本会话」徽章不再误挂在主工作树上。

## 说明

- 远程应答委托的中间正文不再回写委托会话，最终把工具调用与正文一次性写入历史，下次应答能读到上次的工具结果。

## 发布：v0.93.0

## 功能

- **每个会话的工作树与分支各自独立**：新建会话不再复用别人已经检出的分支，目录名与分支名统一为「日期-会话号」，终端默认目录直接落在本会话的工作树里。
- **分支下拉可以直接选中已经建好的工作树**：已被工作树检出的分支带标记，选中就把会话绑到那个目录，不再新建；分支切换下拉里这类分支置灰不可点，免得点了才报错。
- **会话首页的两张 Git 卡合并成一张「环境」卡**：变更、当前分支、最新提交三行一眼看完，分支可以就地展开切换。
- **已打开文件在幕墙上各占一块磁贴**：不再只显示前几个、也不再静默截断，每块都能单独关闭，当前文件用主色标出。
- **Git 面板的仓库栏分成「工作树」和「其他仓库」两组**：当前仓库的工作树排在上面并标出各自分支，最近打开过的排在前面。
- **Git 面板的分支列表按时间排序、按名字里的斜杠折成分组**：当前分支置顶，其余按末次提交时间倒序，每条后面显示「多久之前」。
- **Git 面板的分支行显示与上游的差距**：领先、落后、分叉用箭头和颜色标出，上游被删时给出警告。
- **在别的分支上发送消息会被拦下**：按下发送时若仓库当前分支与本会话记录的不一致，先弹窗确认，选「继续对话」才发送。
- **头像裁剪弹窗重做**：改成方形取景框，带实时圆形预览、缩放滑块和重置，裁剪出来的就是最终头像的样子。
- **连接器设置只留名称一栏，改名会真正保存**：不再展示没有意义的连接器 ID，改完立即写进定义并同步。
- **代码块、表格、图表不再把气泡切成两半**：它们和前后文字处在同一个气泡里。
- **时间线按钮贴底时也能悬停展开**：展开期间底部操作条淡出，两个入口不再打架。

## 优化

- 关闭气泡背景时，正文与分段线贴齐头像左缘，分隔线贯穿整宽、段间距加倍。
- 宽屏下正文与思考 / 工具面板让出左侧头像列、对齐名字左缘，左右留白对称；窄屏保持原样。
- 思维链预览条改为滚动停止 3 秒就浮出，不用再等 10 秒。

## 修复

- 思维块展开收起不再跟着流式乱跳：流式中只默认展开最新一块，手动收起后不会被顶开，按钮与内容保持一致。
- 任务还在排队或有引导消息时不再提前弹「已完成」通知，一次交互只提醒一次。
- 内容相同的多个 mermaid 图不再互相顶掉。
- 变基进行中不再允许切换分支，也不会再抛出一串看不懂的原始报错。
- 触摸屏笔记本上悬停才出现的图标（如侧栏新建会话的铅笔）现在能正常显示。
- 微信联系人配置里遗留的空字段不再导致读取失败（用户反馈）。

## 发布：v0.91.0

## 功能

- **部门退出，组织关系改由人格承载（升级后需要重新设置）**：配置页不再有「部门」与「部门树」两个页面，原来由部门承担的权责——可委托的下级、驱动模型、权限范围、办事指南——全部改由人格承担。升级后旧配置会在启动时自动迁移：内置部门对应到内置人格，自定义部门的办事指南转成一份同名技能并常驻到原成员人格上，模型与权限并入这些人格，下级关系上提到它们最近的上级人格；内置的 HR、leader、saddler 三个人格不再提供。部门里没有成员时，这部分模型与权限无法保留，请到人格页按人格重新确认委托人、模型与权限后再使用。
- **人格页重做**：人格详情分为「资料」与「能力」，「能力」下是随身技能与加载顺序、权限、委托人三块；随身技能可以调整注入顺序，权限可以选择不限制 / 黑名单 / 白名单，并逐项勾选内置工具、技能与 MCP 工具。
- **系统准则开关**：每个人格的提示词首位固定注入系统准则（反谄媚、执行边界与输出风格等基础约束），可在「加载顺序」里关闭；关闭前会提示「AI 的行为会变得不可预测」，确认后才生效。
- **联系人处理人改为选择人格**：远程消息渠道设置里的「处理部门」换成选择处理人格，联系人消息仍进入各自独立会话。
- **能力商店对接 AI**：可以让 AI 直接从能力商店搜索并安装 MCP 连接器和技能，不必在商店页里逐条点。
- **预设技能整理**：原来的技能安装、MCP 安装、助理空间、私有组织四份指南合并为一份「PAI 配置指南」，并新增 reviewer、support 两份常驻技能。
- **会话时间线**：时间线恢复为悬停展开的蛇形布局，尾部新增预览点；时间线入口旁增加「概览」按钮。

## 优化

- 配置页各页头部统一为「常驻面包屑 + 下划线页签」：面包屑只指示当前位置，进入详情时在原位追加一级，不再多出一个返回按钮。
- 配置页列表卡片去掉阴影、只保留描边；供应商与连接器列表里的搜索、数量文案一并收掉。
- 新建会话与委派的对象列表不再出现系统人格（副手、pai system）；草稿的收件人卡片不再显示模型与供应商名，只在没配模型时提示，原有「招募专家」实验入口移除。
- 思考预览条压成两行，思维链展开时让位给「回到底部」。

## 修复

- 让 AI 设置头像时，安装版下头像会写到另一个目录、界面读不到，现在写入位置与读取位置统一。
- 人格页删除人格后没有真正保存，切页或刷新后人会重新出现，现在确认删除后立即落盘。
- Git 面板里选了别的仓库后，重新打开面板或切换会话会退回工作区根仓库，现在按会话记住各自的选择。
