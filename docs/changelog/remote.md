# 变更日志

## 发布：v0.91.0

## 功能

- **部门退出，组织关系改由人格承载（升级后需要重新设置）**：配置页不再有「部门」与「部门树」两个页面，原来由部门承担的权责——可委托的下级、驱动模型、权限范围、办事指南——全部改由人格承担。升级后旧配置会在启动时自动迁移：内置部门对应到内置人格，自定义部门的办事指南转成一份同名技能并常驻到原成员人格上，模型与权限并入这些人格，下级关系上提到它们最近的上级人格；内置的 HR、leader、saddler 三个人格不再提供。部门里没有成员时，这部分模型与权限无法保留，请到人格页按人格重新确认委托人、模型与权限后再使用。
- **人格页重做**：人格详情分为「资料」与「能力」，「能力」下是随身技能与加载顺序、权限、委托人三块；随身技能可以调整注入顺序，权限可以选择不限制 / 黑名单 / 白名单，并逐项勾选内置工具、技能与 MCP 工具。
- **系统准则开关**：每个人格的提示词首位固定注入系统准则（反谄媚、执行边界与输出风格等基础约束），可在「加载顺序」里关闭；关闭前会提示「AI 的行为会变得不可预测」，确认后才生效。
- **联系人处理人改为选择人格**：远程消息渠道设置里的「处理部门」换成选择处理人格，联系人消息仍进入各自独立会话。
- **能力商店对接 AI**：可以让 AI 直接从能力商店搜索并安装 MCP 连接器和技能，不必在商店页里逐条点。
- **预设技能整理**：原来的技能安装、MCP 安装、助理空间、私有组织四份指南合并为一份「PAI 配置指南」，并新增 reviewer、support 两份常驻技能。
- **会话时间线**：时间线恢复为悬停展开的蛇形布局，尾部新增预览点；时间线入口旁增加「概览」按钮。

## 优化

- 配置页各页头部统一为「常驻面包屑 + 下划线页签」：面包屑只指示当前位置，进入详情时在原位追加一级，不再多出一个返回按钮。
- 配置页列表卡片去掉阴影、只保留描边；供应商与连接器列表里的搜索、数量文案一并收掉。
- 新建会话与委派的对象列表不再出现系统人格（副手、pai system）；草稿的收件人卡片不再显示模型与供应商名，只在没配模型时提示，原有「招募专家」实验入口移除。
- 思考预览条压成两行，思维链展开时让位给「回到底部」。

## 修复

- 让 AI 设置头像时，安装版下头像会写到另一个目录、界面读不到，现在写入位置与读取位置统一。
- 人格页删除人格后没有真正保存，切页或刷新后人会重新出现，现在确认删除后立即落盘。
- Git 面板里选了别的仓库后，重新打开面板或切换会话会退回工作区根仓库，现在按会话记住各自的选择。

## 发布：v0.90.2

## 功能

- **会话时间线改版**：时间线入口由右下角悬停才出现的浮层，换成带文字的直接可点按钮，只要会话里有两轮以上消息就一直在；点开后是一整屏竖排的会话历史，点其中任意一条可直接跳到那条消息，长会话里定位不用再来回滚动。
- **运行卡片活动指示**：主页上正在跑的委托、任务、终端卡片，标题前会亮起一枚闪烁的指示灯，三类卡片颜色互不相同。

## 优化

- 运行监控里的「后台进程」「后台终端」统一简称为「终端」。
- 运行监控不再显示词元数量，会话整理底部的预计占用也去掉了数字后面的单位。
- 对话里的行内代码改为红字、不再带底色，代码密集的段落读起来更清楚。

## 修复

- 一次录音只给一条状态提示：转写成功不再额外弹提示；失败时显示真实原因（例如本地识别连不上服务），不再被「未识别到文本」盖掉。
- 切换界面语言后，会话侧栏的分组页签不再停留在切换前的语言，英文环境下启动即为英文。

## 发布：v0.90.1

## 功能

- **能力商店**：技能来源新增 ClawHub，可浏览、搜索并安装 OpenClaw 社区的公开技能；条目详情里的来源地址现在一点即可在浏览器打开。
- **文件与链接操作**：在对话、归档等位置对文件链接或网页链接点右键会弹出操作菜单——文件可在侧边打开、在 VS Code 中打开、定位文件、另存为、复制路径；网页链接可在浏览器打开或复制链接。
- **看图更直接**：用本身支持读图的模型读取本地图片时，直接把原图交给模型理解，不再先经过一次文字转述。

## 修复

- 录音时切换到别的窗口再松开录音快捷键，录音仍会继续、往往录到上限才停，现在能正常停下。
- 配置窗口变窄时，能力商店、连接器、技能、远程渠道等页面的标题栏与分段切换控件不再被容器裁掉或外凸。

## 发布：v0.90.0

## 功能

- **能力商店**：配置页新增能力商店，可跨魔搭、Smithery、官方 MCP Registry 检索 MCP 与技能并一键安装，装进来的默认是关闭状态；需要密钥的 MCP 会在安装前要求填写。
- **技能管理**：技能此前只能查看和编辑，现在可以整体启用或关闭；列表区分为自定义技能与系统内置技能，自定义技能能改名称、描述和正文，也能删除，内置技能只读；技能附带的其他文件可以直接查看。
- **配置页改版**：技能、供应商、部门、人格、连接器、渠道六个模块，由下拉单选加长表单改为卡片概览，点进卡片看详情；部门与人格增加「自定义 / 系统预设」分类，各模块都支持搜索。
- 人格设定词和技能正文支持 Markdown 预览与编辑切换。

## 修复

- 在输入框用 Tab 打开快捷指令、或用 @ 打开提及面板时，弹层被会话工具条压住、选项看不全，现在正常盖在工具条之上（引入于 v0.89.0）。
- Codex 供应商的模型下拉里缺少 gpt-6-astra，现在会随后端清单自动出现（引入于 v0.84.0）。
- macOS 26 上让 AI 模拟组合键会让应用直接崩溃，现已不再触发（引入于 v0.9.9）。

## 发布：v0.89.0

## 功能

- **PAI CLI（Beta）**：在终端里也能用 PAI。不开窗口、不弹界面，给一句任务跑完一整轮（含多轮工具调用），最终回答直接打在终端上；桌面端配好的 skill 与 MCP 在 CLI 里同样可用。用法 `p-ai run "<任务>" --model <配置>`。
- **流式预览**：聊天窗输入框上方新增预览条。生成中，上面四行思维链按阅读节奏逐行推进，下面一行展示最新一段正文；不生成时显示最新一条回复的正文。它同时接过「回到最新」的入口——聊天窗右下角那个圆形「回到底部」按钮已移除。
- **操作区重做**：时间线按钮、预览条、工作区栏这三处原来各自漂浮的元素，收进输入框上方同一个操作区，分上下两排。贴底时显示下排工作区栏，往上翻时显示上排预览条与时间线按钮。
- 操作区下排的元素改为彼此独立：工作区、运行监控、自动推送各自按条件出现，放不下自动换行，点一次直接执行（原来是一条会伸缩的胶囊，点一次只是展开）。工具栏上的 @ 提及入口去掉，输入框自带的面板已经覆盖。
- 生成过程中向上翻看历史，视口不再被强行拽回底部；回到最下方或点预览条才恢复跟随。
- 发送消息后，你的消息停在视口顶部，回复从下方接上。
- 运行监控胶囊按运行类型分流：只跑委托或任务时打开对应页，只跑后台进程、或多种混合时打开主页卡片墙。
- 主页面板新增「Git 提交」卡，能直接看到最近的提交。
- 设置菜单左侧加上分组标题，部分分组可折叠；折叠时组里有更新提示会在标题上显示红点。

## 修复

- 展开「思考与工具」时思维链先撑开再收起，现在直接以折叠态出现。
- 切换会话后，Git 更改区可能显示成别的会话仓库。
- 切换会话后，正在输出的助理气泡会丢掉流式样式。
- 打开会话先闪出第一条消息、不落在最新一条。
- 左右分栏打开时，时间线浮层会飘出聊天列。
- 自主权限档位在界面上与「全权」混同、权限范围被说小，现在单独显示为「无限制」。

## 发布：v0.85.0

## 功能

- AI 修改文件不再等待审批：工作区权限为「审批」时，新建、修改、重命名、删除文件会直接执行，不再弹出智能评估与人工审批确认；每次改动在执行前仍会留下备份，可以照常撤回。
- AI 删除文件改为移入系统回收站（macOS 为废纸篓），不再永久删除，误删后可以从回收站找回。
- 终端命令审批要求 AI 说明用途：请求执行命令时必须填写这段命令要做什么，审批卡与审批弹窗会直接展示这段说明，方便你判断是否放行。
- 输入面板与提问卡统一为双层卡片：桌面与手机使用同一套布局，等待队列以「露头」方式提示，排队消息不再出现不显示的情况。
- 会话菜单的二级入口改为可折叠的多级点按展开。
- 回复文字的流式呈现更平滑：去掉尾部逐词淡入，改为按内容量自动调节速度。
- 时间轴预览卡字号与正文对齐并加宽，跳转时按距离区分平滑滚动。

## 修复

- 足迹墙「今天」视图在凌晨 0:00-4:00 会漏掉当天用量，现在凌晨时段的数据也会统计进来。
- 修复远程 IM 私聊中你发出的消息被误显示为助理消息、并出现空白头像的问题。
- 修复微信联系人发来的图片和文件收不到的问题，私聊发言人正确显示为本机用户。
- 工具执行被拒绝后仍显示为成功、并照常统计代码增删行数的问题，现在会明确标注已拒绝状态。
- 窗口切回或移动端恢复聊天时的问题：不再需要操作两次才恢复，进程被杀后切回不再无响应，后台正在进行的回复也不会被前台恢复打断。
- 队列出队后后续消息气泡刷不出的问题，队列状态不匹配时也会给出准确提示。
- 新会话的引导气泡有时不显示的问题。
- 便携版更新时程序被占用导致替换失败的问题：现在会等待程序退出后重试，并提供手动替换入口。

## 发布：v0.84.0

## 发布：v0.83.0
