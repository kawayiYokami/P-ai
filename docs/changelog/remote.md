# 变更日志

## 发布：v0.98.14

## 功能

- 提问卡移到输入卡上方单独的一层：答题时下方的输入框照旧可以打字、贴附件、发送，收起后缩成一条提示条，写明还有几道题等待确认
- 提问卡的题号改为紧凑的文字面包屑，未答、已答、当前题分色显示，题目行首直接标出序号
- 答案的预览与发送合并成一个「确认」按钮，先进入预览核对再发送，也可以返回修改

## 修复

- 标签预览卡里消息的左右位置跟着真实发言人来判，别的人格派下来的任务不会再显示在你自己这一侧
- 文件标签的预览卡不再显示聊天气泡，改为显示文件图标与文件名

## 发布：v0.98.12

## 功能

- 提问卡改在输入卡里展开：逐题作答后可以先预览全部回答、附一段补充说明，再一次性发出；收起即回到普通输入，右下角的问号仍在提示还有题没答
- 应用意外退出后自动续跑：重启时把崩溃前正在进行的对话接着跑下去，没来得及处理的排队消息也一并还原
- Web 与 VS Code 侧边栏也能检查、下载并安装应用更新，重启后页面连接断开属正常现象
- 设置页重组：智能体、模型能力、记忆并入「人工智能」分组；智能体详情改为「人格 / 能力 / 权限」三页，委派模型与记忆设置归入能力页，表情库跟着人格走
- 记忆设置页只保留向量化与记忆列表，去掉聊天记录搜索与召回诊断两块
- 内置技能新增自我学习

## 修复

- 先开过开发版再打开正式版时，正式版窗口整体闪退
- Web 与 VS Code 侧边栏的自动化任务清单取不到数据
- 定时器工具列出的定时器里混进了其他会话的条目，现在只列本会话与全局定时器

## 发布：v0.98.11

## 功能

- 首页磁贴墙新增「磁贴 / 网格」两种呈现，可从右面板主页按钮旁的箭头切换，选择会被记住：磁贴态留边留缝、圆角带描边，网格态无缝直角、只留格线
- 右面板顶部改为一条常驻标题栏，切换页面时只换标签不再整条重建；左上角新增后退与前进，可在文件与各会话之间按访问顺序来回，重启后仍能接着走
- 标签条放不下时的溢出入口改为显示溢出数量，点开是一列会话预览卡，卡片里直接排着该会话最近两条消息；追问标签的关闭按钮收进图标那一格，悬停图标让位给关闭
- 变更页（原「工具」页）的改动不再按文件聚合成折叠卡，改为一段一项按顺序平铺：左侧序号可跳转，标题行可点折叠，也能在底部一键折叠或展开全部
- 首页「最近工具」改名「最近变更」并按列表陈列，环境卡、自动化卡与委托卡同步调整；委托卡改为更宽的一格并带身份图标
- 议题看板去掉分组卡片，组之间改用浅竖线分列、拉大列距；议题卡悬停时显示完整标题与备注
- 远程联系人会话的状态胶囊显示下次巡检倒计时，展开卡片可见巡检类型与明细
- 会话可以托管自己的自动化脚本：按间隔或常驻运行，脚本输出一行 JSON 即投进本会话，首页磁贴墙为每个运行中的自动化任务显示一张卡

- 修复应答委托的详情里执行过程重复、步数与耗时对不上
- 修复工具改动的行号整段从 1 开始，与实际文件行号对不上

- 修复追问与队员会话打开时一次读几十条消息，长会话打开明显变慢

## 发布：v0.98.6

## 功能

- 日志换了一套写法：打开日志看到的是中文一句话，不再是满屏 JSON、英文键名和 `api-provider-…` 这类内部 ID。
- 聊天里的 Mermaid 图表换了渲染引擎：箭头不再歪斜、折线横平竖直，配色跟着主题走，字体用界面自带的，断网也能出图。
- 首页委托磁贴重做：顶部是发起人头像、耗时计时和状态灯，中间是任务标题，底部加了工具调用数和 Token 用量。
- 议题看板新建议题可以直接指定状态和负责人，不用再先建成「待议」再改。
- 护航建议条右侧加了关闭按钮，不用再等它自己消失。
- 远程群聊发起应答委托时，会戳一下触发这次委托的群友（仅 QQ / OneBot v11 群聊）。
- 群聊外发一次扣一次能量，点名不受能量与回复冷却限制。
- 人格从单个 agents.json 拆成一人格一文件（config/agents/），哪个文件坏了只跳过它自己，其余人格照常加载。
- 附件改存到各会话自己的目录，压缩后会清掉不再被引用的附件，不再一直占着磁盘。
- 群聊回复可以引用某条消息了：正文开头写 `[#编号]`，发出去就带上被引用的那条（仅 QQ / OneBot v11 群聊）。
- 设置页的 API Keys 改成多行文本框，一行一个。
- 输入面板里按 `#` 引用议题时，列表按状态分组，组头标明状态，行内不再重复挂状态标签。
- 确认、提示、输入框换成应用内统一弹窗，不再弹系统对话框。
- 护航的纠错建议改成一句话，不再长篇列步骤。

## 修复

- 远程群聊的回复改成正文一产出就发出去：之前最后一轮正文被跳过、等着收口补发，收口和委托完成又互相推诿，整轮一条都没发出去。
- 群聊巡检跑过一个周期后，写好的回复被整个吞掉的问题修好了。
- 超长的回复不会再被丢掉：压缩旧消息时只清掉工具调用和内联图片，正文和思维链原样保留，长回复不会被当成多余内容切掉。
- 压缩时不会清掉正在处理的消息：只压已经处理过的部分，之后新进来的消息一条都不压；主动压缩只在联系人从离场转在场那一刻做一次。
- 群聊巡检改成一到点就看一次群：一轮跑完不留残余，不再因为上一轮的批次编号对不上而漏发。
- 群聊点名消息不再只读最后一条，与非点名读同一段完整区间。
- 群聊的多段消息会先等 1 秒安静再合并成一条入库，不再被拆成好几条。
- 用户打断委托时，消息写「已取消」，不再报「人格所有候选模型均失败：api-provider-…」。
- 队员的汇报和派活以队员名义出现，不再显示成「系统」；队员停手时的兜底汇报会立刻插进来，不再排队干等。
- 联系人页同一人格接管的多个联系人不再被折叠掉（之前只显示最近一条，点「加载更多」也刷不出来）。
- 切到没有用户消息的会话时，不再跳到列表顶部并一直向上翻页。
- 回答或拒绝问题后，会话列表的待答角标会消失。
- 供应商保存后，选中项不再跳到另一个供应商；保存报错框不再溢出屏幕且关不掉。
- 撤回面板会显示文件撤不回来的原因；这一轮没改文件时不再提示；只剩一个选项时按钮直接写「撤回消息」。
- 发到 QQ 的消息里，Windows 路径的反斜杠不再被吃掉（E:\github\… 不再变成 E:github…）。
- 助理消息不再在正文前注入发送者昵称。
- Web / VS Code 侧补上「批量取技能简介」，这个能力之前在那边缺失。
- 设置页的未保存提示会列出具体改了哪些字段，不再只说「有未保存的更改」。
- 设置页顶部面包屑不再被挤成两行顶破标题栏。

## 性能

- 图表渲染更轻，安装包体积变小，出图更快。

## 发布：v0.98.5

## 功能

- Codex 供应商现在能直接生图和改图：走它自己的图片接口，不再绕道对话接口。图片模型由 ChatGPT 决定，界面上不再给一个假的版本下拉；可添加的模型清单也从接口实时拉取，拉不到才回落到内置名单。
- 模型请求失败时只重发这一次请求，不会把已经跑过的工具再跑一遍。之前只要这一轮用过工具，后面模型偶发失败就直接放弃，现在能正常重试。
- MCP 服务器配置从裸 JSON 文本框改成表单：传输方式、命令、参数、环境变量、请求头都能逐项填，也可以切回 JSON 直接改。
- 供应商可以套用真实客户端的 User-Agent，内置 45 项，按客户端逐个对齐。
- 复制文本和复制图片收成一个入口，Web 端和桌面端都能用。
- 打开所在目录、在文件管理器里定位文件，走系统能力，不再按平台写死命令。
- 设置页头部重做：标题栏覆盖式常驻，面包屑可点层级用悬停底色，加了返回上一级。
- 联系人页重做成平台和通讯录两个设置面，过滤规则回到渠道设置里，行为设置入口搬到联系人页头。
- 人格文件支持 JSONC，写坏了会自修复：缺失字段自动补齐，坏条目跳过并备份，重读失败不会覆盖当前可用内容。
- 后台任务磁贴按会话树聚合，能看到队员和委托会话里跑了什么命令。
- 恢复了护航模式的开启入口。
- 开发用的 demo 页改成组件库页，从设置页移出，各项只留效果。
- 会话里还有没干完的活时，不发完成通知。

## 修复

- ACP 里模型名显示成可读名（供应商名/模型名），同名多等级才带后缀，不再露出内部 id。
- 无边框窗口重开后可能大于最大化区域，现在按窗口几何判断最大化状态；窗口布局恢复进程内只做一次。
- 设置页内容区铺满，不再居中留大块空白；卡片网格固定列宽，拉宽窗口不再改变行内比例；头部行高固定，不再随有没有 tab 变化。
- 文件阅读器点刷新按钮后侧栏被误收起。
- 调度落盘不再把已经回答过的问题写回「未答」。
- 上下文整理重开的那一轮不再触发第二次整理。
- Web 端复制图片偶尔静默失败，现在先转 PNG 再写剪贴板，文本复制也补了兜底。
- 流式输出的高度跟随改回逐帧推进，滚动条不再跟着高度动画一起抖动；单帧最小步长从 6px 降到 1px，小差额不再一跳一跳。
- 气泡左右留白随窗口宽度连续收缩，不再在某个宽度突变。
- 时间线锚点的可点区域改成整格，鼠标停在两格之间不再什么都不触发。
- 思考与工具块的收起按钮改成胶囊样式，看得出可点，也不再压着正文。

## 性能

- 快速请求的轮次记录改为只存在内存里，保留最近 10 条，不再写进数据库。
