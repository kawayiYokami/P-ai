# 变更日志

## 发布：v0.97.6

## 功能

- **表情库按人格独立，人格详情页新增表情管理。旧的全局表情不会自动带过来，需要到每个人格下重新添加，一个名字只对应一张图。**
- **任务正常推进时护航保持安静，没干完的活不再推给你选。**

## 修复

- **MCP 工具权限勾选与实际是否生效一致。**
- **助手终止的后台任务不再显示为被用户打断。**

## 发布：v0.97.5

## 功能

- **新增实验性功能：组队会话**。
- **侧边栏认得 git diff 文件**。
- **记忆页与 API 连接测试的反馈改为窗口提示**。

## 修复

- **新建会话选人格时，不再出现「未配置模型」**。
- **在一个窗口处理终端审批，其他窗口的卡片也会撤下**。
- **切换会话或重开 Git 面板后，更改列表会立刻刷新**。
- **护航会读整段对话，也会催助理把活干完**。
- **goal 运行期间不再触发护航**。
- **文件阅读器切回标签不再重新加载**。
- **bmp 图片不再被拒绝**。

## 发布：v0.97.4

## 功能

- **护航建议按对话状态分三种情况给出**：对话顺畅时，护航会给出 2~4 个你接下来可以直接发送的短语；你被误解、卡住或情绪上来时，护航提示你换个问法或先接住你的情绪；助理答非所问、术语堆砌、反复确认、停在汇报上时，护航把修正方向直接给助理下一轮。
- **护航建议不再是一段分析**：建议压缩成一句可直接用的话，不再解释推理过程，也不再复述你们刚刚说过什么；给出的快捷短语就是你自己的口吻，点了就能直接发送。

## 修复

- **修复助理陷入死循环时护航反复叫醒它**：护航原来每次都会把修正意见发给助理，而每次发送都会强制唤醒助理再跑一轮，助理没改好就会一直循环下去；现在护航先提醒助理一次，如果它还在重复，就停止给助理发消息，改为把情况告诉你，并给你一句能直接说出口的打断话。

## 发布：v0.97.3

## 功能

- **助理不再逐句鉴定你的说法**：新的行为准则把用户当作可信赖的伙伴，你的发言按字面理解并据此行动；只有说法与代码、运行结果这类硬事实正面冲突时才带证据提出分歧，夸赞、机械认错和复读批评都不再出现。
- **计划模式先划范围再逐一提问**：进入计划模式后，助理先定下提问范围——需求意图、目标与边界、关键取舍、风险接受度、验收标准；实现方式不再拿来问你，答案不影响计划走向的分叉由助理自己定默认值并写进计划。范围定好后一次只问一个问题，问完即出计划，不再追加。
- **护航建议改为主要发给助理**：护航审查只在助理卡死、连续多轮重复同一内容、需要你亲自打断时才提示你出手；你的表达有歧义这类问题改由助理自己下一轮调整，不再打扰你。护航给出的快捷短语按钮改为按内容宽度排布、自动换行，点击区域也更大。
- **助理走不通的路会换方向**：同一条路连续失败几次后，助理会回头判断方法本身是否可行，必要时带着已查到的发现回来找你，而不是反复重试同一个动作；你批准过的操作，下次遇到仍会再问一次，不会当成长期许可。

## 修复

- **修复悬浮目录树不跟随目录变化**：地址栏悬停弹出的目录树，展开过一次后内容就不再更新，目录里新增文件仍显示旧的；现在目录一变就同步，正在看的目录就地刷新，没展开的等下次展开取最新内容。
- **修复助理被护航审查时你的发言不生效**：助理正在被护航审查时，你发的消息不会打断它，得等审查跑完；现在你一发言，护航审查立即停止，不再落下一份已经过期的建议。

## 发布：v0.97.2

## 功能

- **桌面脚本一次可以回传多张截图**：一个脚本里连续截几张图，模型现在能一次看到每一张，不再只剩最后一张；写多步操作时能按截图逐步核对。
- **桌面操作的坐标改用屏幕像素**：模型现在按截图上看到的像素位置直接写坐标，不用再换算百分比；主屏以外的位置也能直接点到，此前点副屏要额外指定屏幕、坐标还得按那块屏单独换算。

## 修复

- **修复模型调用工具时参数偶尔只传一半的问题**：使用 Responses 接口时，工具调用的参数可能被截断，导致该步操作失败；现在会取完整的参数。
- **修复 Git 面板在后台有 Git 进程时卡住的问题**：写操作撞上 VS Code 等进程占用的 Git 锁时会自动重试，不必再手动点一次；点同步拉取时，本地的提交、切换分支等操作也不再排队等待。

## 发布：v0.97.1

## 修复

- **修复后台委托完成后不会唤醒助理的问题**：模型自己发起的后台委托，结果回来后现在会作为引导插话、并把主助理唤醒继续处理，表现和你在输入框 @某个下级人格发起的委托一致。
- **修复连续调用工具较多的任务会被中途强行中止的问题**：以前模型连续调用工具超过 10 轮就会被截断、整轮直接报失败；现在不再受这个默认上限限制。

## 发布：v0.97.0

## 功能

- **新增「护航」模式**：开启后，每轮回答结束会再给一条沟通建议，可以是给你的点评，也可以是一组可直接点选的下一步；工具栏会出现「护航」标记，和计划模式同一个菜单里开关，开启前会提示这会明显增加 token 消耗。建议只有在你点了某个选项、或自己直接发言之后才消失，切会话、刷新界面都还在。
- **联系人新增 QQ 官方机器人渠道**：填 AppID 与 AppSecret 就能接入 QQ 单聊和群聊，支持收发文本、图片与文件，断线会自动重连；机器人还没过审核时勾上「使用沙箱环境」即可。
- **新建工作树可以直接检出已有分支**：新建工作树时可在「基分支 / 目标分支」间切换。选「基分支」还是从该分支派生新分支；选「目标分支」就是直接检出某个已有分支，工作树名称只作目录名。已被其他工作树检出的分支会标出来并禁止选择。
- **新增开机自启**：设置「常用」页新增「启动」分组，打开开关后登录系统就自动启动 PAI，并且静默待在托盘里、不弹窗口。
- **模型请求失败重试覆盖更多情况**：除了限流和模型空回，服务端错误、连接中断、超时也会重试；重试间隔改为逐步拉长，界面会显示「正在重试」。重试次数由供应商设置里的「失败重试次数」决定，默认 5 次。
- **联系人分组重命名改为就地编辑**：右键分组选重命名后，名字直接变成输入框，回车提交、Esc 取消，错误提示显示在该分组下方。

## 性能

- **长会话里打开撤回预览不再卡顿**：预览只读取要被撤回的那一段，耗时不随会话长度增长。

## 修复

- **修复桌面脚本在目标程序无响应时会卡死、停止按钮失效的问题**：目标窗口不响应时（例如被调试器断点挂住），点击、查元素、截图等操作会一直不返回；现在会限时返回，停止也能真正中断。
- **修复供应商没填并发上限时被当成串行、多会话互相挡住的问题**：以前不填上限等于一次只能跑一个请求；现在不填就是不限制，只有明确设成 1 才串行。

## 发布：v0.96.6

## 功能

- **会话右键菜单新增「跳转所在分组」**：最近区里的会话右键多一项，点它跳到下面分类区中该会话所属的人格 / 项目分组并定位展开。
- **标题栏「新建会话」按钮改为常驻**：以前侧边栏展开时会隐藏，现在始终显示在上下文占用圆环左侧。

## 修复

- **修复使用 Grok 供应商时消息发不出去、界面卡住的问题**：这类会话发出的请求会在准备阶段崩溃，界面停在「准备下文」且停止按钮无效；现在能正常发送，中断也生效。
- **修复系统人格与系统角色的消息无法撤回的问题**：现在和其他消息一样能撤回或创建分支，撤回后不会把内容回填到输入框。
- **修复发送过程中不能随时打断的问题**：以前提交请求还没返回时停止按钮不可用，现在任何时刻都能打断；已有内容先优雅保存，超时才硬中止。
- **修复限流重试时界面卡在「准备上下文」的问题**：额度耗尽不再被误当成限流重试，限流重试会显示倒计时。
- **修复 Codex 供应商删掉最后一个模型后详情页整页消失的问题**：另外点进详情不再被误判成「有未保存修改」。

## 发布：v0.96.5

## 功能

- **无气泡模式：流式输出时过程段先摊开，输出完再折叠**：生成过程中全部展开，结束后收成只留最后一段；手动展开过的结束时不收回。气泡模式仍默认折叠。
- **转发进会话的内容收成折叠块**：后台 shell、委托完成、会话通知、自动推送等转发内容在会话里默认收起，点开看全文。

## 性能

- **超长思维链展开不再卡界面**：几万到几十万字的思维链改用纯文本渲染，绕开富文本逐行解析。

## 修复

- **修复网页端带本机路径的图片显示不出来的问题**：手机/网页端只是投影、没有这些文件，现在一律向后端取图。
- **修复思维链正文重复显示标题那一行的问题**。
- **修复换段后气泡里留下空白的问题**：过程段折叠或工具切开新段时，旧高度会套在新气泡上。
- **修复流式输出时视口先下跳再弹回的问题**。
- **修复右键重命名会话被限制为当前会话的问题**：现在对本地非系统会话都能改，切走时没输完的标题也不会被收掉。
- **修复改字体保存被拒绝的问题**。

## 发布：v0.96.4

## 功能

- **联系人改为按分组管理**：渠道设置收在上方，联系人按自定义分组列在下方，可新建、重命名、删除分组，也可以把联系人移动到分组。组内按平台账号排序，不再跟着最近消息来回跳动。每个联系人的详细设置在卡片里展开，同时只展开一个；也可以按分组批量设置，或整组移动。渠道没连上时，这些设置仍然可以改。

## 修复

- **修复委托把上下文用满后直接失败的问题**：以前会提示缺少调度上下文、无法继续整理。现在会停用后续工具，并要求立刻说明工作为什么没有做完。
- **修复发起审查时「指定 commit」列出别的会话仓库的问题**：现在读取当前会话正在使用的工作树；换会话或换工作树后，不会再留着上一份列表。
- **修复切换人格时把已选模型一起改掉的问题**：人格和模型已经分开选择，换人格会保留当前模型。

## 性能

- **长思维链默认收起**：没有手动展开时不再自动打开。收起时只显示开头一段；正在生成时若手动展开，也只跟随末尾一段，避免几万字把界面卡住。
- **回复变长时少做重复排版**：流式输出不再为了判断气泡宽度把同一段文字反复扫描。

## 发布：v0.96.3

## 功能

- **新增 Grok 登录与图生视频**：可在配置里用 Grok 账号登录，接入 xAI 供应商；图像生成支持 Grok，并新增「图生视频」工具，把图片转成视频，默认生视频模型可在设置里指定。

## 修复

- **修复在追问里给消息创建会话分支被拒绝的问题**：以前在侧边追问里创建分支会提示「源会话不存在或已归档」，现在能正常创建并在主会话中打开。
- **修复「最近」区选择时间窗口后「加载更多」放不出更多会话的问题**：窗口外的会话不再被直接剔除，点「加载更多」能按步进逐步显示，收起后回到初始范围。

## 发布：v0.96.2

## 功能

- **发起委托与代码审查合并为一张卡片**：会话菜单里两个入口合成一个，在卡片顶部切换「发起委托 / 代码审查」；两边都能自选模型，卡片记住上次选的面板。
- **最近区和历史区统一样式**：最近区的标题行与下方历史分组统一外观，折叠箭头移到文字后面、悬停才显示；「最近」左侧管展开收起，右侧切换 12 / 24 / 48 / 72 小时的时间窗口。
- **过程消息支持完成后折叠**：同一条回复里已完成的过程消息收成「上 N 条消息」，点开可看全部；不想折叠可以在开关里关掉。
- **优化工具调用的语义化 UI**：工具调用改为「阅读 agentStore.ts #1090-1210」这类动作加文件名的纯文本，右侧显示增减行数；目标文本可直接点击打开本地文件，外部 MCP 工具统一显示为「链接到 {工具名}」。
- **重做思维链折叠区**：思维链标题吸顶，右上角可折叠，展开与收起在上下两端都能操作，折叠时保留 4 行预览。

## 修复

- **修复在还没有任何提交的空仓库里打开 Git 面板与代码审查会报错的问题**：仓库刚初始化、尚无首次提交时，相关功能按空历史正常显示，不再报错。
