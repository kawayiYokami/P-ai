# 变更日志

## 发布：v0.98.0

## 功能

- **这一版让几个 AI 一起干活成为可能：普通聊天里就能把活分给它们，配一块看板盯进度、一组问题卡等你拍板；聊天的样子、设置页、联网搜索和能力商店也都换了新的。**
- 在任意聊天里都能叫来几个 AI 帮手，把事情分给它们各自去做，做完把结果送回来；谁那边出了错，原始报错也会一并送回你面前。
- 新增一块进度看板：能按泳道或清单看，按状态筛，也能搜编号、标题和执行人；看板里的编号可以直接点进输入框，变成挂在消息上的引用。
- 同一个人手上可以同时挂好几件在办的事，不用等上一件收尾。
- 派活不再挑关系，除了自己和系统播报，其他人都能接；不指定就自动交给副手。
- 派出去的活现在有一页清楚的进展：跑了多久、走到哪一步、用了哪个模型一眼看全，过程按「想了什么、做了什么」成对排好，最后的答复可以一键复制。
- AI 遇到拿不准的会停下来问你：题目排成一张卡，可以选、可以自己写，也可以直接跳过；卡片能收起，有新题时自己弹开，答完一题自动跳到下一题，没答的题数会标在会话上。
- 在常用的代码编辑器里也能直接和 PAI 聊天了：能换模型、中途叫停、翻回之前的对话，编辑器自带的工具也能接着用。
- 联系人页分成两栏，外部聊天和编辑器会话各归各，编辑器那栏按工作目录分组，每条只占一行。
- AI 的思考过程和做过的操作排成一条清楚的时间线，默认摊开给你看，点一下才收起；工具里的参数不再是密密麻麻的原始文本，改成一行一行的清单，长命令会拆开、过长的字会收起来，结果单独放在下面一张卡。
- 这一整块会跟着你设的字号变，思考标题后面标了字数，展开时有动画、长内容不会一下冲过整屏，工具结果回来时从零展开并淡入，看不完可以在里面滚。
- 思考内容现在从头到尾都显示，不再只留最后几千字。
- 代码、表格、图这类内容改成横向铺满整条消息，普通文字还是原来的气泡。
- 工具在跑的时候，消息头直接告诉你它正在做什么、花了多久；文件名太长会中间省略，括号里的说明还留着。
- 底部多了一条思考预览，没内容时不占地方，输出过程中也稳稳地不闪。
- 消息末尾留出了空间，悬浮的工具条不会盖住最后一条；切换会话直接落到最新一条，带一下淡入。
- 外观设置里，白天和黑夜两套各记各的，改一套不影响另一套；主题能在现成搭配和自定义之间切，卡片上补了几种状态色，深色下的品牌色调亮了，不再发闷。
- 界面大小从拖滑块改成四档，消息字号也能单独调四档。
- 设置页改成左右分栏，联网搜索收进供应商页当一个标签，顶上不再重复一个大标题。
- 标签固定宽度，放不下就换行，展开最多四行高、可以在里面滚，尾巴上有收起和更多的按钮；标签再多，当前看的那一个也始终留在眼前。
- 全应用的图标换成同一套细线画法，撤回、切换主题、文件夹这些图形更贴切；忙碌时的小转圈换成四片叶子依次点亮。
- 聊天窗和侧栏换成掺了主题色的哑光底，标签条和下划线统一样式，窗口底做成半透明。
- 代码块、交互卡片和文件预览改在右栏打开；右栏能直接看网页的渲染效果，也能输入本机网址打开页面，外面的网址和本地文件一律不加载。
- 联网搜索换了五家新来源，自动在它们之间挑，并优先接着用上次成功的那家；原来的两家旧来源都撤了。
- 每个搜索来源可以填好几把钥匙，回车就加进去、点叉就删；一把失效会自动换下一把，不会在同一把上反复试，以前填的老钥匙也还在。
- 能力商店换了货源，条目能显示真图标，卡片改成图标、名字、来源加两行说明，下载量按万来显示，简介不用等点进详情才出来。
- 人格页收成三块，原来那页组织管理整块去掉了；没头像的人格保存后会自动画一张，改了名字其他窗口立刻跟着变。
- 有些内置技能现在由系统按场合自动带上，技能面板里这些开关会置灰并写明原因；另外多了一个「给这件事造一个人」的技能。
- 配置工具只留三个动作，改配置直接编辑它给出的文件；改完之后，所有窗口和编辑器里的页面都会自己刷新。
- 快速模型可以干脆设成不配置，等于关掉这档加速；真出了错会弹一张说人话的卡片，不再把一串原始报错印在头像下面。
- 首页重排过：追问和队员不再各占一大块，改成一个入口加一张队员名单，一人一行，卡片大小由布局统一分。
- 输入区菜单里关掉了护航模式的开关，已经开着的会话还能从输入框旁边退出。
- 服务卡片改显示服务自己的一句介绍，地址和标签都去掉了。
- 新建会话时就把模型定下来，不再到读取时才临时换一个。

## 修复

- 改 Windows 上带回车换行的文件，以前会卡上好几分钟、还得先失败一次，现在一次就过。
- 点停止现在停的是你正看着的那一轮，不会停错；关掉追问也重新管用了。
- 改过配置之后，内置技能不再无声无息地消失，会当场找回来。
- 工具跑到一半点停止，不再被说成「模型全挂了」，这一轮已经写出来的内容和工具记录都留着。
- 一轮里已经动过文件、发过命令或消息之后，就算失败也不会再来一遍，这些动作不会重复做。
- 一组工具没全跑完时，没跑到的那些会补一句说明，不再留着「还没回来」的悬空状态。
- 消息写盘失败时会退回去，不再出现内容对不上、整个会话打不开的情况。
- 追问、派活、定时任务这些来源，不能再把内容塞进绑了微信、飞书这类外部聊天的会话往外发。
- 流式输出时画面不再上下跳。
- 窗口窄的时候左右两栏不会叠在一起互相盖住，打开一边另一边会自动收起。
- 网页版和编辑器插件里，没开始录音不会再先跳一次麦克风授权。

## 性能

- 按下停止几乎立刻就能发下一条，不用再等两三秒。
- 工具多、内容长的对话，滚动和展开明显顺了：收起的内容先不画，展开时先给个提示，特别长的文字分段处理。
- 很长的回答写完收尾那一下不再卡一下。

## 发布：v0.97.11

## 功能

- **工具调用一开始执行就出现在消息里，不用等结果回来才显示；中途打断只停住还没返回的调用，已经跑完的结果照常保留。**
- **右栏的追问与队员磁贴显示人格头像，调度中转圈、有未读显示绿色角标、上轮失败显示红色角标，三个状态占同一个位置，一次只出现一个。**

## 修复

- 排队的消息在本会话发出后再切回来，输入框上方不会仍挂着已经发出的那条。
- 手机端回车或点发送后软键盘收起；点底栏按钮也不再先收键盘才执行。
- 撤回排队消息、或把排队消息转成引导后，光标直接回到输入框，可以接着改。
- 发送新消息时历史不再被顶得上下跳，等内容量完做一次平滑上推；引导消息落库时同样平滑滚到底。
- 同一条消息里思考与工具同时只展开一个，跨消息也只保留一个展开位，不再因为同时铺开多块大正文而卡住。
- 思维链贴顶时不再持续往控制台刷警告，页面不会因此发卡。
- 打开追问会话直接落到最新消息，不再停在列表顶部。
- 追问窗口不再冒出主会话的轮次错误；追问压缩时会显示整理中提示并锁住输入。
- 修改文件时若漏了要替换的原文，现在直接报错，不再把整份文件静默清空。
- Web 端与 VS Code 侧边栏点会话索引库的修复不再没反应。

## 性能

- 助理状态显示更准：区分「正在生成工具调用」与「正在执行工具」，准备上下文、等待回应、开始输出各自独立显示。

## 发布：v0.97.10

## 功能

- **助理可以直接用你自己已登录的 Chrome 办事：打开网页、点开链接、填表、读取需要登录才看得到的内容，全程都在你眼前那个窗口里发生，不用另建环境，也不用你重新登录。**
- **项目里的技能不必再给每个人格单独授权，放进去就能用；内置技能仍按原有权限控制。**
- **技能索引按来源分成两棵树，内置与项目各占一棵，每项只写自己的路径和说明，不再把整条路径摊在每一行。**
- **文件阅读器侧边栏收成窄条：有文件在读时悬停展开，离开、滚动或点正文就自动收起，展开按钮与当前模式图标留在条上，换文件不会重新加载。**
- **文件过滤不再每敲一个字就重算整棵树，停手一秒后才生效，清空输入立即恢复。**
- **Git 变更列表按新增、删除、修改、重命名、未跟踪分组，同一状态内按路径排列，被删除的文件名带删除线。**
- **配置页的模型下拉框按内容自适应宽度，名字再长也不会被截掉，最宽不超过屏幕九成。**

## 修复

- 被引导消息打断的半截轮次、被自己停掉的轮次，以及没有真正产出一轮回复的批次，不再发起护航审查，同一段对话不会被反复审。
- 保留对话的摘要不再混进工具调用标记，也不会和工具事件正文重复收录；每句话的说话人按消息自身记录，不再一律记成会话的主人格。
- 从侧栏直接选会话、或批量归档后自动切走时，搜索覆盖页会跟着收起，不再挡在新会话上面。

- 文件阅读器里切换文件后目录树会跟着定位，从外部入口打开文件也不再漏掉定位。
- 用量足迹墙的格子恢复方砖观感，色阶改按当年实际用量分布，日常用量也能看出高低。
- 桌面操作遇到目标窗口卡死时不再长时间无响应，失败时会给出可读原因。

## 发布：v0.97.4

## 功能

- **护航建议按对话状态分三种情况给出**：对话顺畅时，护航会给出 2~4 个你接下来可以直接发送的短语；你被误解、卡住或情绪上来时，护航提示你换个问法或先接住你的情绪；助理答非所问、术语堆砌、反复确认、停在汇报上时，护航把修正方向直接给助理下一轮。
- **护航建议不再是一段分析**：建议压缩成一句可直接用的话，不再解释推理过程，也不再复述你们刚刚说过什么；给出的快捷短语就是你自己的口吻，点了就能直接发送。

## 修复

- **修复助理陷入死循环时护航反复叫醒它**：护航原来每次都会把修正意见发给助理，而每次发送都会强制唤醒助理再跑一轮，助理没改好就会一直循环下去；现在护航先提醒助理一次，如果它还在重复，就停止给助理发消息，改为把情况告诉你，并给你一句能直接说出口的打断话。

## 发布：v0.97.3

## 功能

- **助理不再逐句鉴定你的说法**：新的行为准则把用户当作可信赖的伙伴，你的发言按字面理解并据此行动；只有说法与代码、运行结果这类硬事实正面冲突时才带证据提出分歧，夸赞、机械认错和复读批评都不再出现。
- **计划模式先划范围再逐一提问**：进入计划模式后，助理先定下提问范围——需求意图、目标与边界、关键取舍、风险接受度、验收标准；实现方式不再拿来问你，答案不影响计划走向的分叉由助理自己定默认值并写进计划。范围定好后一次只问一个问题，问完即出计划，不再追加。
- **护航建议改为主要发给助理**：护航审查只在助理卡死、连续多轮重复同一内容、需要你亲自打断时才提示你出手；你的表达有歧义这类问题改由助理自己下一轮调整，不再打扰你。护航给出的快捷短语按钮改为按内容宽度排布、自动换行，点击区域也更大。
- **助理走不通的路会换方向**：同一条路连续失败几次后，助理会回头判断方法本身是否可行，必要时带着已查到的发现回来找你，而不是反复重试同一个动作；你批准过的操作，下次遇到仍会再问一次，不会当成长期许可。

## 修复

- **修复悬浮目录树不跟随目录变化**：地址栏悬停弹出的目录树，展开过一次后内容就不再更新，目录里新增文件仍显示旧的；现在目录一变就同步，正在看的目录就地刷新，没展开的等下次展开取最新内容。
- **修复助理被护航审查时你的发言不生效**：助理正在被护航审查时，你发的消息不会打断它，得等审查跑完；现在你一发言，护航审查立即停止，不再落下一份已经过期的建议。

## 发布：v0.97.2

## 功能

- **桌面脚本一次可以回传多张截图**：一个脚本里连续截几张图，模型现在能一次看到每一张，不再只剩最后一张；写多步操作时能按截图逐步核对。
- **桌面操作的坐标改用屏幕像素**：模型现在按截图上看到的像素位置直接写坐标，不用再换算百分比；主屏以外的位置也能直接点到，此前点副屏要额外指定屏幕、坐标还得按那块屏单独换算。

## 修复

- **修复模型调用工具时参数偶尔只传一半的问题**：使用 Responses 接口时，工具调用的参数可能被截断，导致该步操作失败；现在会取完整的参数。
- **修复 Git 面板在后台有 Git 进程时卡住的问题**：写操作撞上 VS Code 等进程占用的 Git 锁时会自动重试，不必再手动点一次；点同步拉取时，本地的提交、切换分支等操作也不再排队等待。

## 发布：v0.97.1

## 修复

- **修复后台委托完成后不会唤醒助理的问题**：模型自己发起的后台委托，结果回来后现在会作为引导插话、并把主助理唤醒继续处理，表现和你在输入框 @某个下级人格发起的委托一致。
- **修复连续调用工具较多的任务会被中途强行中止的问题**：以前模型连续调用工具超过 10 轮就会被截断、整轮直接报失败；现在不再受这个默认上限限制。
