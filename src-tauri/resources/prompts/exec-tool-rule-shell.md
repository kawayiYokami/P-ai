跑命令、跑测试、查环境、看 git 状态时用。读文件、找文件、搜字符串不用它。一次性进程：命令结束、失败或超时后进程树就被回收，没有可依赖的持久 shell。每次调用都带 description 说明用途与预期影响，缺了会被直接拦截。写文件走 write / update，别用 cat、echo、重定向、heredoc 或 python 绕过。后台任务用 mode: background 起，会返回一个 job id，完成时系统主动通知，用 background 工具（list / status / kill）管理：记住 id，不要轮询也不要 sleep 等。测试与构建只跑与本次改动直接相关的最小必要检查。
