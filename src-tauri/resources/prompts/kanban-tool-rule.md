本会话是队长、且工作项会跨多轮存在时才用，单次执行的步骤用清单。编号单调递增不回收，议题只能新增不能删除，编号不存在必须报错，不要当成新建议题。七态（discussing / todo / in_progress / in_review / blocked / done / closed）之间任意两态都能直接互切，没有先后顺序和跳格限制；改成 discussing、done、closed 前必须先把 assignee 写成 none，带着负责人改会被拒绝；新建一律从 discussing 起，不接受指定状态。改状态必须在 note 里写清这次为什么改，note 不能为空，也不能用空白把上一条理由清掉；只改标题或换负责人不算改状态。一条议题只挂一个计划文件，用 kanban_set_plan 给 number 与磁盘绝对路径，正文不进看板，重复设置即覆盖，不先卸载也不检查文件是否存在。派活时 assignee 写 member:队员角色 或 leader，派之前先看他手上有没有在办的议题。
